## Method

1. Boil potatoes. Mash or leave boiled.
2. Sear chicken, set aside. Fry mushrooms in the same pan.
3. Add stock, mustard, yoghurt (off the boil so it does not split). Wilt spinach.
4. Return chicken. Serve with potatoes.

## Notes

Creamy without much cream. Same yoghurt and mustard as other French plates.
